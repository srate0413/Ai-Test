# 牛马复仇记

公司欠薪三个月，老板的饼一天没断。联合牛马同事收集线索，用 AI 做资料、已读不回、甩出公司黑料和终极大招劳动仲裁完成行动。

在线玩：https://srate0413.github.io/Ai-Test/

- 手机摇杆、四向可爱现代办公角色；战略部默认短发女生。
- 开始后随机发布经理目标和额外委托，04接待区证据快递每局必拿。
- 只有总经理、副总和反复去楼梯间抽烟的阿木有探测视线；发现即触发交替回合战斗。
- 经理随机巡视、与同事及彼此交流；同事面对面吐槽欠薪，头顶交替聊天气泡。
- 14名角色各有欠薪证言，证言可整理为战斗证据；公开讨薪或秘密协商改变后续路线。
- 倒地人物会引来围观；靠近围观者会被审问，可解释、出示证据或请人事处理。
- 必须等修门的老周实际离开才可通过西侧，完成任务后从22电梯或23楼梯离场。
