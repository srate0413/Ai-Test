# 老板下线大作战

手机竖屏卡通办公室潜行 + 回合制职场嘴炮游戏。

**在线玩：https://srate0413.github.io/Ai-Test/**

- 左下摇杆移动，点击地面寻路；右侧紫色互动、粉色背后突袭、黄色职场论战。
- 13 技术部身份为工程师，14 战略发展部为兼助理。完成 06 总经理或 08 副总经理之一，再从 22 电梯或 23 楼梯安全离场。
- 老周守在 15 门口：闲聊和轻步不能通过。给螺丝刀等他修完离开，交设备报修单支开，或赢得盘问论战。
- 回合论战可用“卡报销”“优惠券攻击”“甩锅护盾”等。看对手下一招，留意弱点、连携、灵感和冷却。工程师有“需求变更”，兼助理有“会议连环套”。
- 财务挪车、报销等待、HR约谈、打印机故障、奶茶结盟和电话诱导均实际改变NPC行动。
- 同事会调查最后出现的位置；在盟友房间、神秘小屋等处藏身可等待搜索结束。
- 每局两张随机支线，完成后有额外奖励；安全撤离评定等级并保留本设备最高分。

纯静态，无服务器和账户。直接用静态服务器运行本目录即可。美术许可与开源对标见 [CREDITS.md](CREDITS.md)，升级说明见 [GAMEPLAY-UPGRADE.md](GAMEPLAY-UPGRADE.md)。

本作是虚构卡通游戏，机关仅为抽象状态和计时，不包含现实配方或破坏步骤。
