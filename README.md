# 老板下线大作战
基于用户办公区设计的手机竖屏卡通潜行游戏。纯静态，可直接打开 dist/index.html，或通过静态服务器打开。

## 操作与规则
- 左下方向键 / WASD / 方向键移动；点击地面寻路；轻步按钮或 Shift 减速潜行。
- E / 紫色互动键：对话、机关、取物。F / 粉色突袭键：从背后接近非盟友。
- 必须完成 06 总经理或 08 副总经理至少一个，再从22电梯或23楼梯安全撤离。老板500分，其他同事100分。
- 13工程师：预约汇报、白板演示、借工具。14兼助理：签字协调、送特制茶。
- G01六人独立行动；财务挪车后报销者等待；人事约谈和打印故障分散员工；奶茶使16成为盟友。
- 15门口后勤修锁：在13/14借工具、交给老周，12秒后完成。21封闭走廊不是出口。
- 手机、任务、动态面板打开时暂停。页面失去焦点时暂停，可点右上继续。

## 目录
- dist：完整可部署游戏及CC0素材。
- check-game.cjs：导航、碰撞、NPC联动、目标与撤离规则的自动检查。
- verification.json：最近一次检查记录。
